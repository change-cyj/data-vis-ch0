6.1

盒模型

每个 HTML 元素都是一个盒子，理解 content / padding / border / margin 四层结构是布局的基础。

讲解

CSS 中每个元素都是一个矩形盒子，由内到外分为四层：content（内容）→ padding（内边距）→ border（边框）→ margin（外边距）。

默认情况下，width 只设置 content 区域的宽度。设置 box-sizing: border-box 后，width 包含 content + padding + border，布局更直观。

margin 是特殊的——相邻元素的 margin 会合并（取较大值），这是很多布局间距问题的根源。

关键代码
/* 盒模型四层结构 */
.box {
  width: 200px;        /* content 宽度 */
  height: 100px;
  padding: 20px;      /* 内边距 */
  border: 2px solid #333; /* 边框 */
  margin: 16px;       /* 外边距 */
  box-sizing: border-box; /* width 含 padding+border */
}

6.2

定位机制

static / relative / absolute / fixed / sticky 五种定位，决定元素在页面中的位置。

讲解

CSS position 属性有五个值：

static（默认）：按文档流排列，top/left 无效。relative：相对原位置偏移，不脱离文档流。absolute：相对最近的定位祖先，脱离文档流。fixed：相对视口固定，滚动不动。sticky：滚动到阈值前 relative，超过后 fixed。

z-index 只对非 static 元素生效，控制堆叠顺序。

关键代码
/* 五种定位 */
.pos-static   { position: static; }
.pos-relative { position: relative; top: 10px; left: 20px; }
.pos-absolute { position: absolute; top: 0; right: 0; }
.pos-fixed    { position: fixed; bottom: 20px; }
.pos-sticky    { position: sticky; top: 0; z-index: 100; }

6.3

Flex 弹性布局

一维布局之王：flex-direction / justify-content / align-items 三大属性掌控主轴与交叉轴。

讲解

Flex 布局将容器分为主轴（main axis）和交叉轴（cross axis）。flex-direction 决定主轴方向（row/column），justify-content 控制主轴对齐，align-items 控制交叉轴对齐。

子元素的 flex-grow 控制剩余空间分配，flex-shrink 控制空间不足时的收缩，flex-basis 设置初始大小。

Flex 适合一维布局（行或列），Grid 适合二维布局（行列同时控制）。

关键代码
/* Flex 容器 */
.flex-container {
  display: flex;
  flex-direction: row | column;
  justify-content: center | space-between | ...;
  align-items: center | flex-start | ...;
  gap: 16px;
}
/* Flex 子项 */
.flex-item {
  flex: 1 0 200px; /* grow shrink basis */
}

6.4

Grid 网格布局

二维布局之王：grid-template-columns / rows 定义行列，gap 控制间距，areas 命名区域。

讲解

Grid 布局同时控制行和列两个维度。用 grid-template-columns 和 grid-template-rows 定义网格轨道，gap 设置行列间距。

repeat() 和 minmax() 是两个强大函数：repeat(3, 1fr) 等分三列，minmax(200px, 1fr) 限制最小最大值。

grid-area 可以给区域命名，然后用 grid-template-areas 像画图一样布局。

关键代码
/* Grid 网格布局 */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto;
  gap: 16px;
}
/* 命名区域布局 */
.layout {
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

6.5

响应式设计

用 @media 媒体查询适配不同屏幕尺寸，移动优先的设计策略。

讲解

响应式设计的核心是媒体查询：@media (max-width: 768px) 在小屏幕下应用不同样式。

移动优先策略：先写小屏幕样式，再用 @media (min-width: ...) 逐步增强大屏体验。

配合 viewport 元标签、rem/em 相对单位、clamp() 流体字号，实现真正自适应的布局。

关键代码
/* 移动优先：小屏默认，大屏增强 */
.grid { grid-template-columns: 1fr; }
@media (min-width: 768px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1024px) {
  .grid { grid-template-columns: repeat(3, 1fr); }
}
/* 流体字号 */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
