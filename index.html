数据加载与类型转换

从 CSV 文件读取 80 条新生记录，理解 d3.csv 的加载与类型转换机制。

讲解

CSV 是纯文本格式，d3.csv() 解析后所有字段默认都是 String。如果直接用 d.age 做加法，结果会是字符串拼接而非数值运算。

解决方法是在 d3.csv(url, row) 的第二个参数 row 回调 中做类型转换：用 +d['年龄'] 转 Number，用 new Date(d['生日']) 转 Date。

转换后的数据才能参与后续的统计、分组和可视化。

关键代码
// 字段映射：中文列名 → 英文属性
const map = { "序号":"id", "姓名":"name", "年龄":"age" };

// row 回调：逐行转换类型
function transformRow(d) {
  return {
    id: +d["序号"],              // + 转 Number
    name: d["姓名"].trim(),
    age: +d["年龄"],             // 数值
    birthday: new Date(d["生日"]), // 日期
    class: d["班级"].trim(),
  };
}

// 一行完成加载 + 转换
const data = await d3.csv("data/newstudent.csv", transformRow);

数据定义：DIKW 金字塔

从原始数据到智慧的四层递进，理解可视化在信息层的核心作用。

讲解

DIKW 金字塔将认知分为四层：数据（Data）→ 信息（Information）→ 知识（Knowledge）→ 智慧（Wisdom）。

数据是原始离散的观察值；信息是经过处理、赋予上下文的数据；知识是对信息的提炼理解；智慧是运用知识做决策。

可视化的主要目标是信息层——将原始数据转化为可读的图形，帮助人快速获取信息。

关键代码
// DIKW 四层定义
const DIKW = [
  { tier: "wisdom", name: "智慧",
    def: "运用知识做决策" },
  { tier: "knowledge", name: "知识",
    def: "对信息的提炼理解" },
  { tier: "information", name: "信息",
    def: "赋予上下文的数据",
    viz: "可视化主要目标 ✅" },
  { tier: "data", name: "数据",
    def: "原始离散观察值",
    viz: "原始 CSV / 表格" },
];

// 梯形绘制：宽度逐层递增
DIKW.forEach((d, i) => {
  const ratio = (i + 1) / 4;
  const tw = 70 + ratio * 48;
  const bw = 70 + (ratio + 0.25) * 48;
  g.append("path")
    .attr("d", `M ... L ... L ... L ... Z`)
    .attr("fill", d.color);
});

数据属性：Stevens × Mackinlay

Stevens 测量尺度决定数据能做什么运算，Mackinlay 通道排序决定用什么视觉编码。

讲解

Stevens 测量尺度将数据分为四类：名义（Nominal）、序数（Ordinal）、区间（Interval）、比率（Ratio）。每类允许的运算不同——名义只能判等，序数可比较大小，区间可加减，比率可乘除。

Mackinlay 通道排序（1986）将视觉通道按对定量数据的感知有效性排序：位置 ≈ 长度 > 角度 > 面积 > 亮度 > 色相 ……

两者结合：数据类型 → 选择合适的视觉通道。定类数据用色相，顺序数据用亮度，定量数据用长度/位置。

关键代码
// Stevens 四尺度的允许运算
const STEVENS = {
  nominal:  { ops: "= / ≠", ch: "色相" },
  ordinal:  { ops: "< / >", ch: "亮度" },
  interval: { ops: "+ / -", ch: "位置" },
  ratio:    { ops: "× / ÷", ch: "长度" },
};

// Mackinlay 通道有效性分数
const channels = [
  { ch: "位置", score: 1.0 },
  { ch: "长度", score: 0.94 },
  { ch: "角度", score: 0.88 },
  { ch: "面积", score: 0.70 },
  { ch: "亮度", score: 0.82 },
  { ch: "色相", score: 0.85 },
];

// 按分数绘制排序条形图
x = d3.scaleLinear().domain([0,1]).range([0,w]);
g.selectAll("rect").data(channels).join("rect")
  .attr("width", d => x(d.score));

1.4

数据变换函数

D3 提供 map / filter / sort / group / rollup 等函数，将原始数据转化为可视化所需的结构。

讲解

D3 的数据变换函数大多可类比数组方法，但返回新数组不修改原数据，且支持更强大的分组聚合。

map / filter / sort 对应数组的同名方法；reduce 做汇总；group 按键分组保留所有元素（类似 GROUP BY）；rollup 分组后只保留聚合结果（类似 GROUP BY + COUNT）；cross 做笛卡尔积；bin 做分箱（直方图前置步骤）。

关键代码
// 按班级统计人数（rollup）
const counts = d3.rollup(
  data,              // 输入数据
  v => v.length,     // reducer：每组的聚合
  d => d.class       // key：分组依据
);
// → Map { "软件1班": 24, "软件2班": 20, ... }

// 按班级分组保留所有元素（group）
const groups = d3.group(data, d => d.class);

// 年龄分箱（bin）
const bins = d3.bin()
  .thresholds([17, 18])
  (data.map(d => d.age));

1.5

        
选择器与 Data-Join

        
理解 D3 的 enter / update / exit 三态，掌握数据驱动 DOM 的核心机制。

      


      

        

          
讲解

          

            
Data-Join 是 D3 的核心思想：数据与 DOM 元素绑定。当数据变化时，D3 自动计算三种状态：

            
enter：数据多于元素 → 新增元素（绿色）。update：数据与元素一一对应 → 更新属性（墨绿）。exit：元素多于数据 → 移除元素（红色）。

            
key 函数（如 d => d.id）绑定元素身份，避免数据重排时全部元素错乱——类比 React 的 key。

          

        

        

          
关键代码


// Data-Join 核心三态
const sel = svg.selectAll("circle")
  .data(data, d => d.id);  // key 函数

// enter：新增
sel.enter().append("circle")
  .attr("fill", green);

// update：更新
sel.attr("fill", dark);

// exit：移除
sel.exit()
  .transition().style("opacity", 0)
  .remove();

// 合并 enter + update
sel.enter().append("circle")
  .merge(sel)
  .attr("r", d => d.value);
